# Быстрый старт Aegis Core

## Требования

- Windows 10 или новее
- Python 3.10 или новее
- Node.js 18 или новее (для сборки интерфейса)

## Установка

Из корневой папки проекта установите зависимости Python:

```powershell
pip install -r requirements.txt
```

Соберите React-интерфейс:

```powershell
Set-Location frontend
npm install
npm run build
Set-Location ..
```

Запустите приложение:

```powershell
python main.py
```

Для запуска нужен собранный файл `frontend/dist/index.html`. Скрипт `run.bat`
подскажет команды сборки, если файл отсутствует.

## Первый запуск

Можно сразу продолжить как гость или создать учетную запись по электронной
почте. Данные учетной записи хранятся локально в `aegis_users.db`; пароль
сохраняется как PBKDF2-хеш. Параметр «Запомнить меня» сохраняет сессию на
устройстве, а без него сессия завершается при закрытии приложения.

В разделе **Мой аккаунт** доступны редактирование профиля, выход и выбор темы.
Гостевой профиль можно сохранить локально либо преобразовать в учетную запись.

## Проверка файлов

- **Быстрая проверка** — доступные временные папки, Downloads и Desktop с
  ограничением числа файлов.
- **Расширенная проверка** — домашняя папка и отдельные системные каталоги,
  также с ограничениями глубины и количества файлов.
- **Выбрать файл** — проверка одного выбранного файла.

Найденные локальным сканером файлы можно переместить в карантин. В разделе
**Карантин** можно восстановить файл или удалить его окончательно.

Приложение выполняет проверки по запросу. Оно не обеспечивает постоянную
защиту в реальном времени и не отслеживает USB-устройства. Содержимое файлов
не загружается; если настроен ключ VirusTotal, хеши файлов могут отправляться
для внешнего поиска. По умолчанию ключ не задан. Результат проверки не является
гарантией безопасности файла.

## Контекстное меню Windows

При необходимости можно добавить команду проверки файла в контекстное меню:

```powershell
python main.py register
```

Удаление команды:

```powershell
python main.py unregister
```

## Сборка исполняемого файла

После сборки React-интерфейса установите PyInstaller и выполните:

```powershell
pip install pyinstaller
pyinstaller main.spec
```
